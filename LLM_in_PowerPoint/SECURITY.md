# 安全与数据说明

## 数据会流向哪里

LLM_in_PowerPoint 是本机 PowerPoint 加载项，但模型推理通常发生在所选 CLI 的服务端，并非完全离线。

- 首轮或上下文变化时，会把整份演示文稿的文字（按页列出，不含演讲者备注）作为上下文交给所选的 Claude Code / Codex CLI。只选一条要点也可能发送全篇；很长的演示文稿按目标所在页及附近截取。
- 只有点了「当前页截图」才会发送幻灯片图片。图片和 PDF 附件会先写入系统临时目录，请求结束时清理。
- 对话历史、输入草稿和目标位置（页 ID、形状 ID、字符位置和原文）保存在面板的本地存储中，不写进演示文稿。CLI 自身也可能在其会话目录中保存对话，具体受 CLI 设置约束。
- 本项目不要求在仓库中配置 API key，也不提供云端代理。

## 本机边界

服务只监听 `127.0.0.1`，默认端口 `8387`。macOS 注册用户级 launchd 服务，数据放在 `~/.llm_in_powerpoint/`；Windows 使用当前用户的启动快捷方式，数据位于 `%LOCALAPPDATA%\LLM_in_PowerPoint`。不要把该端口转发或暴露到公网；这个服务不是面向多用户的身份认证网关。

macOS 安装时如果发现 LLM_in_Word 已信任的本机证书，会把证书和私钥复制到 `~/.llm_in_powerpoint/cert`（私钥权限 600）并沿用，不再新建和信任第二张证书。证书只对 `localhost` / `127.0.0.1` 有效。卸载 PowerPoint 版时不会删除钥匙串里的证书，因为 Word 版可能还在使用。

Claude 纯文本请求不启用工具，带附件的请求只启用 Read；Codex 使用只读沙箱并禁止交互式批准，但仍可能加载本机配置中的工具。账户与数据处理规则由对应 CLI 及其服务提供方管理。

## 报告问题

请不要在公开 Issue 中粘贴密钥、真实演示文稿或带凭证的日志。若仓库已启用 GitHub Private Vulnerability Reporting，可使用 Security 页面的 “Report a vulnerability”；否则请通过已有的私有渠道联系维护者。另见[仓库安全说明](../SECURITY.md)。
