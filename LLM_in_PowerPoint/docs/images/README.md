# Screenshots / 截图说明

Captured on 2026-10-01 in **Microsoft PowerPoint for Mac 16.109** with the LLM_in_PowerPoint 0.1.0 pane and its local service. The decks were written for the screenshots; in the Chinese deck the text is tagged as Chinese and the theme's Chinese font is PingFang SC, as in a deck typed in Chinese PowerPoint. Selections and button clicks were scripted inside the pane to keep the takes repeatable; PowerPoint, the pane and every reply are real. Replies came from the local Claude Code CLI (claude-haiku-4-5, low effort). The pane was opened through a development copy of the manifest, so the task pane's title bar is cropped out; everything below it is the normal pane.
