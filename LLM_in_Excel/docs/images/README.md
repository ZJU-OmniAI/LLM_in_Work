# Screenshots / 截图说明

Frames from the demo recording made on 2026-10-01 in **Microsoft Excel for Mac 16.109** with the LLM_in_Excel 0.1.0 pane and its local service. The workbooks were written for the demo; they contain deliberate problems (stray spaces, mixed case, an amount stored as text, a missing date). Mouse movements, clicks and typing were scripted so the takes are repeatable; Excel, the pane and every reply are real. Replies came from the local Claude Code CLI (Sonnet 5.5, low effort). Each image is the window below the ribbon and above the sheet tabs; Excel's own interface is in Chinese on this Mac. The demo workbooks open the pane automatically, and in these recordings a second, unused LLM_in_Excel tab shows next to the pane's title.

截图取自 2026-10-01 在 **Mac 版 Microsoft Excel 16.109** 中录制的演示视频，使用 LLM_in_Excel 0.1.0 面板和本机服务。工作簿为演示专门编写，故意带了一些问题（多余空格、大小写不一、存成文本的金额、缺失的日期）。为便于重复录制，鼠标移动、点击和输入由脚本完成；Excel、面板和所有回答都是真实的，回答由本机 Claude Code CLI（Sonnet 5.5，low）生成。每张图截取窗口中功能区以下、工作表标签以上的部分；这台 Mac 上 Excel 本身的界面是中文。演示工作簿会自动打开面板，录制时面板标题旁多出一个未使用的 LLM_in_Excel 标签页。

Files without a suffix show the English interface; `.zh-CN` files show the Chinese interface. / 不带后缀的是英文界面，`.zh-CN` 是中文界面。
