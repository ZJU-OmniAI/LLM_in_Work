📄 LLM_in_PDF

本机 Claude Code / Codex，接入你的 PDF 工作流

发送问题会把正文、选段与框图交给所选模型服务；原 PDF 保存在本地，不被改写。

直接读取浏览器中的本地 PDF：在扩展「详情」开启「允许访问文件网址」。也可直接选择或拖入文件，无需开启该权限。

macOS / Linux：在下载的 LLM_in_PDF 目录运行
./install.sh
在线 PDF 可自动打开；其他论文网页点「读取当前论文网页」。Chrome 会自动拉起本机桥程序。
Windows / HTTP 备用：在 PowerShell 的 LLM_in_PDF 目录运行
npm start
保持终端开启。
