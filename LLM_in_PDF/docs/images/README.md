# PDF screenshots

`pdf-reader.jpg` and `pdf-image-chat.jpg` were captured from the real LLM_in_PDF extension in an isolated Chromium profile. The two-page source PDF is generated from `../../../docs/video/demo-paper.html` and contains clearly labelled synthetic values. Answers were generated by Claude Code (Sonnet 5.5, low effort), via the real local HTTP bridge.

Reproduce from the repository root with `node docs/video/record-pdf.mjs` after installing the documented dependencies. No personal documents or browser history are used.
