# Screenshot notes / 截图说明

Cropped on 2026-09-30 from the LLM_in_Work demo recordings. The page is a local demo workspace that runs the real LLM_in_Overleaf extension (0.9.0) and a real CodeMirror editor with sample LaTeX; it is not the hosted Overleaf website. Mouse and keyboard input were scripted to keep the recording steady. Every reply was generated by the real Claude Code CLI (claude-sonnet-5-5, low effort) through this project's native host. The recording harness forwards the browser's messages to that host, so Chrome's installed Native Messaging registration is not part of these images. No personal document, account page or credential appears.

截图于 2026-09-30 取自 LLM_in_Work 演示录屏。页面是本地演示工作区，运行真实的 LLM_in_Overleaf 扩展（0.9.0）和真实的 CodeMirror 编辑器，文稿为示例 LaTeX，并非 Overleaf 官网。为保证录制稳定，鼠标和键盘操作由脚本完成。所有回答由真实 Claude Code CLI（claude-sonnet-5-5，low）经本项目的本机桥生成；录制脚本把浏览器消息转发给本机桥，因此不涉及 Chrome 已安装的 Native Messaging 注册。画面中没有个人文档、账号页面或凭据。

Files without a suffix show the English interface; `.zh-CN` files show the Chinese interface. / 不带后缀的是英文界面，`.zh-CN` 是中文界面。

| Image | What it shows / 内容 |
| --- | --- |
| `overleaf-selection` | Two passages collected from `main.tex`, panel open / 从 `main.tex` 收集两段，面板已打开 |
| `overleaf-diff` | A separate diff for each selection / 每个选段各自的差异 |
| `overleaf-applied` | The editor after applying both passages / 两段都应用后的编辑器 |
| `overleaf-ask` | Ask mode with `refs.bib` attached, checking citations / 附加 `refs.bib` 后用问答模式检查引用 |

`node tools/capture-docs.cjs [--lang=zh-CN]` captures a simpler selection / diff / applied set on a smaller demo page. It needs a signed-in Claude Code CLI and Chrome, makes one real model request and consumes quota.
