# Screenshots / 截图说明

Cropped on 2026-09-30 from the LLM_in_Work demo recordings in **Microsoft Word for macOS** with the installed LLM_in_Word 0.7.1 add-in and its local service. The document text was written for the demo. Mouse and keyboard input were scripted to keep the recording steady; the add-in, Word and every reply are real. Replies came from the local Claude Code CLI (claude-sonnet-5-5, low effort).

截图于 2026-09-30 取自 LLM_in_Work 演示录屏：**macOS 版 Microsoft Word**，使用本机安装的 LLM_in_Word 0.7.1 加载项和本机服务。文档内容专为演示编写。为保证录制稳定，鼠标和键盘操作由脚本完成；加载项、Word 和所有回答都是真实的，回答由本机 Claude Code CLI（claude-sonnet-5-5，low）生成。

Files without a suffix show the English interface; `.zh-CN` files show the Chinese interface. / 不带后缀的是英文界面，`.zh-CN` 是中文界面。

| Image | What it shows / 内容 |
| --- | --- |
| `word-selection` | Two targets added and an instruction typed / 添加两个目标并输入要求 |
| `word-diff` | The diff for one target, with **Apply all** / 单个目标的差异预览和「应用全部」 |
| `word-tracked-changes` | Applied edits as tracked changes, with the Review tab / 以修订写入后的文档和「审阅」功能区 |
| `word-table` | Table preview in which only the inserted row is new / 表格预览：只新增一行 |
| `word-ask` | Document Q&A with a three-point summary / 文档问答：三条要点总结 |

In the English take, the pane reports the plain-text fallback for the edited paragraphs; in the Chinese take the formatting was preserved. Formatting preservation is best effort. These images show macOS Word; interactive testing in Windows Word is a separate acceptance step.

英文演示中，侧栏提示该段改用纯文本写入；中文演示中格式原样保留。格式保留属于尽力而为。以上为 macOS Word 画面，Windows Word 的交互验收需另行进行。
